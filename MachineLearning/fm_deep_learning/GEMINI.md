# 프로젝트 개요

이 프로젝트는 PyTorch를 활용한 영화 추천 시스템 구현을 목표로 합니다. 특히, 단순한 추천 시스템 구현을 넘어, 소프트웨어 공학의 **SOLID 원칙**을 적극적으로 적용하여 설계되었습니다. 이를 통해 코드의 가독성, 유지보수성, 확장성을 극대화하고, 머신러닝 시스템 개발의 모범 사례를 제시하고자 합니다.

## 핵심 목표

-   **PyTorch 기반 추천 시스템 학습 및 서빙**: `Matrix Factorization` 모델을 PyTorch로 구현하고 학습시킨 후, FastAPI를 이용한 API 서버를 통해 서빙하는 전체 과정을 실습합니다.
-   **SOLID 원칙 적용**: 단일 책임 원칙(SRP), 개방-폐쇄 원칙(OCP), 의존성 역전 원칙(DIP)을 적극적으로 적용하여 모듈화된 아키텍처를 구축합니다.
-   **머신러닝 워크플로우 이해**: 데이터 준비, 모델 학습, 평가, 저장, 활용(API, 테스트)에 이르는 머신러닝 프로젝트의 전반적인 생명 주기를 이해합니다.
-   **문서화의 중요성**: `README.md`를 통해 프로젝트의 개요, 구조, 실행 방법, 트러블슈팅, 기술 용어 해설 등 상세한 정보를 제공하여 초보자도 쉽게 접근하고 이해할 수 있도록 합니다.

## 기술 스택

-   **Python**: 핵심 프로그래밍 언어
-   **PyTorch**: 딥러닝 모델 구현 및 학습 프레임워크
-   **Pandas, NumPy**: 데이터 처리 및 분석
-   **scikit-learn**: 데이터 분할 등 유틸리티
-   **FastAPI**: 학습된 모델을 서빙하기 위한 비동기 웹 프레임워크
-   **Uvicorn**: FastAPI 애플리케이션을 실행하는 ASGI 서버

## 아키텍처 및 설계 원칙

-   **모듈화된 `src` 디렉토리**:
    -   `config.py`: 모든 설정과 하이퍼파라미터를 중앙 집중식으로 관리.
    -   `data_loader.py`: 데이터 로딩, 전처리, `DataLoader` 생성 등 데이터 관련 모든 책임을 캡슐화.
    -   `model.py`: `MatrixFactorization` 모델의 아키텍처 정의만을 담당.
    -   `evaluator.py`: 모델 평가 로직(`evaluate` 함수)을 담당.
    -   `trainer.py`: 모델 학습 루프를 담당하는 `Trainer` 클래스 캡슐화.
-   **명확한 실행 스크립트**:
    -   `train.py`: 학습 파이프라인의 메인 진입점으로, `src` 모듈들을 조립하여 학습을 실행.
    -   `api.py`: 학습된 모델을 활용하여 예측 및 추천을 제공하는 FastAPI 서버.
    -   `test_model.py`: 모델 로드 및 기능 테스트 스크립트.

## 커밋 메시지 정책

-   **형식**: `type(scope): subject` (`type`은 영어, `subject`는 한국어)
-   **Type**:
    -   `feat`: 새로운 기능 추가
    -   `fix`: 버그 수정
    -   `docs`: 문서 변경 (README, GEMINI 등)
    -   `refactor`: 코드 리팩토링 (기능 변경 없이 구조 개선)
    -   `chore`: 빌드 시스템, 라이브러리 설치 등 기타 변경

## 학습 목표

이 프로젝트를 통해 사용자는 다음과 같은 내용을 익힐 수 있습니다.

-   PyTorch를 사용한 딥러닝 모델 구현 및 학습의 기본 원리.
-   추천 시스템의 핵심 알고리즘 중 하나인 `Matrix Factorization`의 동작 방식.
-   FastAPI를 이용한 머신러닝 모델 서빙 방법.
-   SOLID 원칙을 실제 프로젝트에 적용하여 견고하고 확장 가능한 코드 작성 능력.
-   머신러닝 프로젝트의 데이터 준비부터 모델 활용까지의 전체 워크플로우.
-   상세하고 사용자 친화적인 문서 작성의 중요성.
