# AI 입문자를 위한 파이썬 데이터 분석 예제 모음

이 프로젝트는 데이터 분석과 머신러닝의 기초를 배우는 비전공자 및 입문자를 위해 제작되었습니다. 각 파이썬 파일(`*.py`)은 특정 데이터 분석 기법이나 알고리즘을 실제로 어떻게 적용하는지 보여주는 구체적인 예제입니다.

코드에는 각 줄의 의미를 설명하는 상세한 주석이 포함되어 있으니, 코드와 함께 이 문서를 참고하여 학습하시기 바랍니다.

---

## ⚙️ 예제 파일 목록 및 설명

### 📄 `amazone_pivot_table.py`

아마존 리뷰 데이터를 사용하여 '피벗 테이블(Pivot Table)'을 생성하는 예제입니다. 피벗 테이블을 통해 사용자와 제품 간의 평점 관계를 한눈에 볼 수 있는 표로 재구성하고, 비어있는 평점을 채우는 방법을 학습합니다.

- **주요 개념**: `pandas` 라이브러리, 피벗 테이블, 데이터 정제, 결측치 처리.

### 📄 `height_weight_analytic.py`

키와 몸무게 데이터를 시각화하고, 데이터의 주요 분포 특성을 나타내는 '고유값(Eigenvalue)'과 '고유벡터(Eigenvector)'를 계산하는 예제입니다.

- **주요 개념**: `matplotlib` 시각화, `numpy` 공분산 행렬, 고유값/고유벡터.

### 📄 `iris_analyst.py`

머신러닝의 "Hello, World!"와 같은 붓꽃(iris) 데이터를 불러와, 데이터 특징들 간의 관계를 나타내는 '공분산 행렬'을 계산하는 기초 예제입니다.

- **주요 개념**: `scikit-learn` 예제 데이터셋, 행렬 곱셈, 공분산.

### 📄 `iris_data_lda.py`

붓꽃 데이터를 '선형 판별 분석(LDA)'을 사용하여 2차원으로 축소하고 시각화하는 예제입니다. LDA는 데이터의 '분류'에 초점을 맞춰, 각 품종을 가장 잘 구분하는 새로운 축을 찾습니다.

- **주요 개념**: **지도 학습** 차원 축소, 선형 판별 분석(LDA), 데이터 표준화.

### 📄 `iris_data_pca.py`

붓꽃 데이터를 '주성분 분석(PCA)'을 사용하여 2차원으로 축소하고 시각화하는 예제입니다. PCA는 데이터의 품종 정보 없이, 순수하게 데이터의 '분산'이 가장 큰 방향을 새로운 축으로 찾습니다.

- **주요 개념**: **비지도 학습** 차원 축소, 주성분 분석(PCA), 데이터 표준화.

### 📄 `merge_practice.py`

여러 엑셀 파일에 나뉘어 있는 데이터를 `pandas`의 `merge` 기능을 사용해 하나의 큰 데이터 표로 합치는 예제입니다. 실무에서 가장 중요한 데이터 전처리 과정 중 하나입니다.

- **주요 개념**: `pandas` 데이터프레임 병합, 레프트 조인, 데이터 집계.

### 📄 `svd_practice.py`

'특이값 분해(SVD)'의 원리를 학습하고, 이를 이용해 '평점 예측'을 수행하는 추천 시스템의 핵심 로직을 구현한 예제입니다.

- **주요 개념**: SVD의 수학적 원리, 행렬 분해와 복원, 잠재 요인 모델.

### 📄 `recommand_svd.py`

SVD 모델을 구축하고, 학습된 모델이 얼마나 정확한지 성능을 평가하는 전체 과정을 담은 종합 예제입니다.

- **주요 개념**:
    - 추천 시스템 모델링 및 성능 평가
    - 학습/테스트 데이터 분리의 중요성
    - 모델 평가 지표: **RMSE** (평균 제곱근 오차), **MAE** (평균 절대 오차)

#### 💡 주요 파라미터 상세 설명

`recommand_svd.py` 코드의 `svd_predict_model`와 `performance_metrics` 함수에는 모델의 동작과 성능에 큰 영향을 미치는 주요 파라미터(인자)들이 있습니다.

1.  **`degree` (SVD의 잠재 요인 수)**
    - **무엇인가요?**: SVD가 사용자-영화 관계를 분석할 때 사용할 '숨겨진 중간 다리' 또는 '주요 특징'의 개수입니다. 예를 들어, 영화를 '액션성', '코미디성', '작품성' 등 몇 개의 보이지 않는 요인(Latent Factor)으로 분석할지 정하는 값입니다.
    - **왜 설정하나요?**: 원본 데이터는 매우 복잡하지만, 사용자의 취향은 몇 가지 핵심적인 요인의 조합으로 설명될 수 있다고 가정합니다. `degree`를 통해 복잡한 데이터를 더 단순한 핵심 요인들의 조합으로 압축하여, 노이즈를 제거하고 사용자가 평가하지 않은 항목의 평점을 '추론'할 수 있게 됩니다.
    - **설정 기준은?**: `degree`는 '하이퍼파라미터'로, 정해진 답이 없습니다. 값이 너무 작으면 중요한 특징을 놓쳐 예측 성능이 떨어지고, 너무 크면 사소한 특징(노이즈)까지 학습하여 오히려 새로운 데이터에 대한 예측을 못하는 '과적합(Overfitting)'이 발생할 수 있습니다. 보통은 여러 `degree` 값으로 모델을 테스트해보고, RMSE 같은 성능 지표가 가장 좋게 나오는 값을 선택합니다.

2.  **`test_size` (테스트 데이터 비율)**
    - **무엇인가요?**: 전체 데이터 중 모델의 성능 평가에만 사용할 데이터의 비율입니다. `test_size=0.2`는 20%를 테스트용, 나머지 80%를 학습용으로 사용하겠다는 의미입니다.
    - **왜 설정하나요?**: 모델을 평가할 때는 반드시 '학습에 사용되지 않은, 처음 보는 데이터'를 사용해야 합니다. 만약 모델이 공부한 문제(학습 데이터)로 시험(테스트)을 보면 100점이 나오겠지만, 그건 실력을 제대로 측정한 것이 아닙니다. `test_size`는 바로 이 '처음 보는 시험 문제'를 확보하기 위해 설정합니다.
    - **설정 기준은?**: **8:2** 또는 **7:3**이 가장 보편적으로 사용되는 비율입니다. 정답은 없지만, 데이터가 아주 많다면 테스트 데이터 비율을 10% 또는 그 이하로 줄이기도 하고, 데이터가 아주 적다면 학습 데이터를 더 많이 확보하기 위해 테스트 비율을 줄이고 '교차 검증(Cross-validation)' 같은 다른 방법을 사용하기도 합니다.

3.  **`random_state` (랜덤 시드값)**
    - **무엇인가요?**: 데이터를 무작위로 섞거나 나눌 때, 그 무작위성을 '고정'하는 숫자입니다. '랜덤이지만, 언제나 똑같은 순서로 랜덤하게' 만들어주는 역할을 합니다.
    - **정확히 어떤 의미인가요?**: `train_test_split` 함수는 실행할 때마다 데이터를 다른 방식으로 무작위로 나눕니다. 이렇게 되면 코드를 실행할 때마다 테스트 결과(RMSE 등)가 미세하게 달라져서, 내가 수정한 로직 때문에 성능이 좋아진 것인지 단순히 데이터가 운 좋게 나뉜 것인지 알 수 없게 됩니다.
    - **재현성을 위한 시드값**: `random_state=42`와 같이 특정 숫자를 지정하면, 이 함수는 내부적으로 42라는 '시드(seed)'를 사용하여 랜덤 난수 생성기를 초기화합니다. 그 결과, 몇 번을 실행해도 항상 동일한 방식으로 데이터를 나누게 됩니다. 따라서 다른 사람이 내 코드를 실행하거나, 내가 나중에 다시 실행해도 **정확히 동일한 결과가 나오는 '재현성'**이 보장됩니다. 숫자 자체(42)는 어떤 것을 써도 상관없으며, 단지 고정된 값을 사용한다는 것이 중요합니다.
